# Kermach

Термінали для Claude Code і Codex на Electron. Кожен проєкт відкривається в окремому вікні.
Агенти працюють в окремому фоновому процесі, тому не зупиняються, коли закриваєш вікно.
Відкрив вікно знову — вкладки та їхній вивід на місці.

Це пробна версія. Перевірено тільки на Windows 10 і 11, 64 біти.

## Що вміє

- Список проєктів: у кожного свій колір і значок, кожен відкривається у своєму вікні.
- У вікні проєкту — вкладки Claude, Codex і звичайний термінал PowerShell.
- Агент закінчив роботу — звучить сигнал, на вкладці з'являється позначка.
- Плагіни:
  - «Файли» — дерево папки проєкту і пошук;
  - Git;
  - перегляд Markdown;
  - вбудований браузер: елемент сторінки або знімок екрана можна передати агентові;
  - автоматизації через Планувальник завдань Windows;
  - залишок лімітів Claude і Codex;
  - кольорові теми;
  - інтерфейс українською, англійською та німецькою;
  - кольорова рамка вікна проєкту.

## Що потрібно

- Windows 10 або 11, 64 біти.
- [Claude Code](https://claude.ai/code). Codex — за бажанням, ставиться окремо.

Готову збірку для Windows (zip, без встановлення) можна отримати в автора.
