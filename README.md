# Kermach

Термінали для Claude Code і Codex на Electron. Кожен проєкт відкривається в окремому вікні.
Агенти працюють в окремому фоновому процесі, тому не зупиняються, коли закриваєш вікно.
Відкрив вікно знову — вкладки та їхній вивід на місці.

Перевірено на Windows 10 і 11, 64 біти.

## Що вміє

Повний опис усіх функцій — у файлі [FUNCTIONS.md](FUNCTIONS.md). Коротко:

- Список проєктів: у кожного свій колір і значок, кожен відкривається у своєму вікні. Групи, закріплення, пошук.
- У вікні проєкту — вкладки Claude, Codex, інших агентів (Gemini, Grok, Antigravity) і звичайний термінал PowerShell. Розкладки на 2–4 термінали.
- Агенти не зупиняються, коли закриваєш вікно. Після перезавантаження комп'ютера розмови Claude і Codex продовжуються з того самого місця.
- Агент закінчив роботу або чекає відповіді — звучить сигнал, приходить сповіщення, на вкладці з'являється позначка.
- Точки повернення: знімок файлів проєкту після кожної відповіді агента, відкат однією кнопкою.
- Копії проєкту (git worktree) для великих або ризикованих правок.
- Команда `kermach` для агентів: агент сам читає браузер, запускає картки, шукає по коду, бачить інші вкладки.
- Плагіни:
  - «Роадмап» — дошка карток проєкту: картку можна віддати агентові, окремий перевіряльник дивиться, чи її виконано;
  - «Справи» — список завдань для людини: терміни, повтори, мітки, нагадування;
  - «Історія» — минулі розмови з агентами, пошук і продовження;
  - вбудований браузер: агент читає сторінку, а з вашого дозволу натискає й заповнює поля;
  - автоматизації: завдання для агента за розкладом через Планувальник завдань Windows;
  - «Файли» — дерево папки проєкту і пошук;
  - Git — гілка, змінені файли, зміни порядково;
  - редактор Markdown;
  - залишок лімітів Claude і Codex;
  - «Промпти» — які файли з інструкціями отримає агент;
  - кольорові теми;
  - інтерфейс українською, англійською та німецькою;
  - кольорова рамка вікна проєкту.

## Що потрібно

- Windows 10 або 11, 64 біти.
