Термінали для Claude Code і Codex на Electron. Кожен проєкт відкривається в окремому вікні.
Агенти працюють в окремому фоновому процесі, тому не зупиняються, коли закриваєш вікно.
Відкрив вікно знову — вкладки та їхній вивід на місці.

Це пробна версія. Ця гілка — порт для **macOS на Apple Silicon (M1 і новіші)**; оригінал перевірено на Windows 10 і 11, 64 біти.

## Що вміє

- Список проєктів: у кожного свій колір і значок, кожен відкривається у своєму вікні.
- У вікні проєкту — вкладки Claude, Codex і звичайний термінал (на Mac — ваша оболонка входу, зазвичай zsh; на Windows — PowerShell).
- Агент закінчив роботу — звучить сигнал, на вкладці з'являється позначка.
- Плагіни:
  - «Файли» — дерево папки проєкту і пошук;
  - Git;
  - перегляд Markdown;
  - вбудований браузер: елемент сторінки або знімок екрана можна передати агентові;
  - автоматизації: на Mac — через launchd (LaunchAgents), на Windows — через Планувальник завдань;
  - залишок лімітів Claude і Codex;
  - кольорові теми;
  - інтерфейс українською, англійською та німецькою;
  - кольорова рамка вікна проєкту.

## Теми і вид «Розмова»

У «Налаштуваннях» → «Тема програми» є чотири теми:

- **Тема Ростислава** — оригінальний вигляд Kermach (з палітрами плагіна «Теми»).
- **Скло** — рідний macOS: напівпрозора бічна панель, системний шрифт і акцент, вміст на картках.
- **Студія** — спокійний вигляд для читання, як у застосунках Claude і Codex (шрифт Onest).
- **Пульт** — щільний інтерфейс з рамками і моноширинними підписами (Golos Text, JetBrains Mono).

У трьох нових темах є «Оформлення»: як у системі, світле або темне.

**Вид «Розмова»** для вкладок Claude і Codex: кроки агента згортаються в прогрес з назвами («Читає…», «Виконує…»),
відповіді оформлені як Markdown, запит дозволу — картка з кнопками. Поле введення пише в той самий термінал,
тож слеш-команди й решта функцій працюють як завжди. Перемикач «Розмова / Термінал» є в кожній вкладці,
вид за замовчуванням — у «Налаштуваннях». Розмова береться з журналу сесії, який агент веде сам
(`~/.claude/projects/…` для Claude, `~/.codex/sessions/…` для Codex), а не з екрана терміналу.

## Що потрібно

- macOS 12 або новіша на Apple Silicon (M1 і новіші). Intel-Mac не підтримується.
- [Claude Code](https://claude.ai/code). Codex — за бажанням, ставиться окремо.

## Встановлення на Mac

1. [Завантажте `Kermach-0.1.0-arm64.dmg`](https://github.com/delorostislavbiz/kermach/releases/download/v0.1.0-mac/Kermach-0.1.0-arm64.dmg), відкрийте його і перетягніть Kermach у «Програми».
2. Збірка підписана ad-hoc, без сертифіката Apple. Якщо macOS пише, що програму «пошкоджено» або «не вдалося перевірити»
   (так буває з файлом, завантаженим з інтернету), один раз виконайте в Терміналі:
   `xattr -dr com.apple.quarantine /Applications/Kermach.app`
3. Дані програми лежать у `~/Library/Application Support/TERMINALUS`, автоматизації — у `~/Library/LaunchAgents/com.kermach.automation.*.plist`.
   При першому запуску Kermach переносить проєкти з Orca, якщо вона встановлена.

## Збирання з коду (Mac)

Потрібні Node.js 22 і Xcode Command Line Tools (`xcode-select --install`).

```sh
npm install
npm run rebuild   # node-pty під Electron, arm64
npm start         # запуск з коду
npm run dist      # dist/Kermach-<версія>-arm64.dmg і .zip
```

## Що змінено для macOS

- Автоматизації: launchd замість Планувальника завдань (`plugins/automations/schedule-mac.js`), сповіщення — Центр сповіщень macOS.
  Чого launchd не вміє сам («один раз», «догнати пропущений запуск» після вимкнення, «не доганяти»), перевіряє сам прогін.
- Прогін автоматизації бере PATH з оболонки входу: launchd дає урізаний PATH, і `claude` не знаходився б.
- Вікно автоматизацій — з рідними кнопками вікна macOS, як інші вікна; підказки клавіш — ⌘ замість Ctrl.
- Перенесення проєктів з Orca — з `~/Library/Application Support/orca`.
- Збирання: electron-builder, `.app` / `.dmg` / `.zip` для arm64, іконка `build/icon.icns`.

Решту Mac-гілок (оболонка, unix-сокет демона, PATH, Dock, меню, Finder, ps замість PowerShell) заклав ще автор оригіналу.
